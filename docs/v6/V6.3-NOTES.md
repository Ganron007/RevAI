# V6.3 — Single-mode Agentic RE

> **Status:** DONE MVP 2026-07-22 · **No RevAI** (ship once after V6.4)  
> **CLI:** `/opt/scripts/pipeline_single_v63.py`  
> **Deep stage:** always `deep_dive_agentic.py` (no size-based standard/large deep fork)

## Model

```
intake → quick_scan → deep_dive_agentic → [optional dynamic] → yara → publish → section → audit
```

- `pipeline_mode=single` + `stage_trace.json` (replayable)
- HITL: `REVENG_HITL_VERDICT=1` stops before publish if quick≠deep
- Dynamic: `REVENG_DYNAMIC=1` or `--dynamic` → `dynamic_run_v2.py` (V6.2)

## Usage

```bash
# full spine (agentic deep; no Flare)
python3 /opt/scripts/pipeline_single_v63.py /path/to/sample.exe

# resume from session + optional Flare dynamic
REVENG_DYNAMIC=1 python3 /opt/scripts/pipeline_single_v63.py --sha <sha256>

# HITL gate
REVENG_HITL_VERDICT=1 python3 /opt/scripts/pipeline_single_v63.py --sha <sha256>
```
